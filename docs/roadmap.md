# Roadmap sugerido

## Fase 1 (MVP - 4 a 6 semanas)

Objetivo: salir a producción con flujo de compra básico.

- Auth: registro/login
- Catálogo: listado + detalle
- Carrito
- Checkout básico
- Integración con un PSP para pago + token de tarjeta
- Admin: CRUD de usuarios, ítems, precios, descuentos, imágenes
- Historial simple de órdenes

Criterio de salida:
- Cliente puede comprar producto o servicio de punta a punta.
- Operador puede crear/editar ítems y publicar cambios.

## Fase 2 (Escalado funcional)

- Recuperación de contraseña y verificación de email
- Búsqueda avanzada y recomendaciones
- Cupones y promociones por segmentos
- Gestión de agenda para servicios más robusta
- Notificaciones por email/whatsapp
- Reportes en Admin (ventas, conversión, top ítems)

## Fase 3 (Optimización)

- App móvil (React Native o Flutter)
- Multi-moneda y multi-país
- Motor antifraude
- Arquitectura orientada a eventos
- Observabilidad avanzada (tracing, SLOs)
