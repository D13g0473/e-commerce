# Admin App

Aplicación de gestión operativa.

## Funcionalidades objetivo

- Gestión de usuarios y roles
- Gestión de catálogo (productos/servicios)
- Gestión de precios y descuentos
- Gestión de fotos e imágenes
- Gestión de órdenes

## Rutas sugeridas

- `/login`
- `/dashboard`
- `/usuarios`
- `/catalogo`
- `/precios-descuentos`
- `/ordenes`
- `/media`
